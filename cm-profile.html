Design notes · CM profile

  1. Now a settings page, opened from your name in the top-right menu (no longer in the sidebar). A stand-in for single sign-on: each CM picks themselves once with "Working as"; it's remembered on that computer. Later, SSO fills this in automatically and the selector goes away.
  2. The people list comes from the team roster stored privately on the server (not in the code repository). Managers can edit it. India GCC uses only the listed associates.
  3. Training matrix. Leads update it. The "trained since" date feeds Team insights, so managers can see IR time since someone learned a skill. The list of case types can be edited.
  4. The profile makes the site smarter. If a case needs training this CM doesn't have yet (e.g. VUL), the workstation opens in Guided and shows a "new to you" tip. When reassigning, trained CMs are suggested first.
  5. Personal settings for the timer, celebrations, and notifications. Celebrations can be turned off fully; the timer auto-start can be turned off, but IRs then need a manual start.
