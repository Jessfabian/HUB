Design notes · Admin console

  1. Only Admin accounts see this page; the server blocks everyone else. Your account (Fabian, Jessie · Account Manager MMSD) has Manager + Admin + Dev access, so you also see Team insights, User accounts, and the Developer tools.
  2. Run the site from the browser: restart, maintenance mode, a site-wide banner ("Quest is down until 2 PM"), deploy a new version, and roll back. Risky actions ask for your password again and are logged.
  3. Feature switches let you turn a feature off quickly if it misbehaves, or pilot it with one team first.
  4. Most day-to-day changes (steps, templates, forms, chatbot answers) are content, not code, so they are edited here, previewed, and published without a redeploy.
  5. Dev-only: logs, backups/restore, tests, API explorer, and server settings. Code changes still go through the repo (python app.py runs it locally on port 5001), then deploy here.
