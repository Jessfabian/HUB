Design notes · Ready-to-issue case (view mode)

  1. View mode is the default for any case you aren't actively working on, and the "View" button in My cases opens it. It shows just the essentials: where the case is, what's next, key facts, requirement status, and recent activity. Nothing on it can be edited.
  2. ✎ Work on this case (or the ✎ Work mode switch at the top) opens the full checklist for the current stage, here the Issue stage. Sections you mark Done lock again.
  3. The status banner turns green when nothing is outstanding ("Ready to issue"), stays blue while work is in progress, and turns grey when the case hasn't been touched in a while.
