Design notes · Firm directory

  1. One shared list of firm/agency # → account manager, backup, and DocuSign approval. It replaces typing the AM on every case.
  2. Three ways to keep it current (your answer): managers and the AM team lead can edit any row in the site, and the existing sheet/report can be imported. Every change logs who made it and when.
  3. The workstation and email builder read it automatically. A CM can still override the AM on a single case.
  4. Import shows a preview of changes before applying, so a bad file can't wipe the list. Later the report import can run on a schedule.
