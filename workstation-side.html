Design notes · Option 2 (Side-by-side)

  1. The workstation is a guide plus checklist. Data entry and output stay in the existing IR workbench, which is re-skinned to match (see wireframe).
  2. One click opens the workbench (same case, new tab). Steps deep-link to the matching workbench section.
  3. The profile collapses into a summary bar to give the checklist more room. Edit expands it (try it).
  4. BOT example: when BOT = Yes, "Act on BOT note" appears and the manual sweep disappears.
  5. A mapping table shows which workbench section supports which step.
    Trade-off: less rebuilding now, but CMs work across two pages and two profile forms. Option 1 removes that duplication.
