Design notes · Forms library

  1. Same content as today's forms library, in the shared shell.
  2. Search by everyday names: each form has nicknames (part 1, owner form, HIPAA, HIV, PAC, POA, trust cert, bene form…). Search forgives typos and partial words. One result per form; the state picker (or the open case) picks the right state version.
  3. The 'Used when' column links each form to the profile answer that triggers it. 'Attach to email' adds the correct state version to the open case's email.
